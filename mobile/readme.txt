### Folder structure

src
├───builder                     -- base folder for builder
│   └───react-native            -- builder made with react-native components
├───components                  -- base folder for components
│   └───react-native            -- base folder for react-native components
│       ├───edit-control        -- react-native components builder mode
│       ├───registrator         -- react-native components registrators in component registry
│       ├───renderer            -- react-native components renderers
│       │   └───collection      -- react-native components renderers for collection subcomponent
│       └───view-control        -- react-native components viewer mode
└───shared                      -- shared folder for react/react-native
    └───control                 -- shared control code
        └───collection-editor   -- shared control code for collection-editor
