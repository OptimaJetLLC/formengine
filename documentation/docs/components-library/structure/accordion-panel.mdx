# Accordion panel

The Accordion panel is a collapsible content section inside an [Accordion](/components-library/structure-components/accordion). Add form
components to its content area and use the header to describe the section.

## Panel behavior

The Form Builder keeps every panel expanded so its nested components remain editable. In the Form Viewer, the parent Accordion controls
which panels are expanded.

The Form Builder assigns contiguous event keys when you add, move, reorder, or remove panels. The keys preserve the selected panel as the
order changes.

## Main properties

The following properties are available within the _Main_ tab:

| Name      | Type      | Description                                                        |
|-----------|-----------|--------------------------------------------------------------------|
| Header    | `string`  | Sets the text displayed in the panel header                        |
| Event key | `string`  | Identifies the panel to its parent Accordion                       |
| Body fill | `boolean` | Makes the content area fill the available panel body               |
| Bordered  | `boolean` | Displays a border around the panel                                 |
| Shaded    | `boolean` | Displays a shadow around the panel                                 |
| Content   | `node`    | Contains the form components displayed inside the panel            |

See the [RsAccordionPanelProps API reference](/api-reference/@react-form-builder/components-rsuite/interfaces/RsAccordionPanelProps) for
the full React component API.
