## Introduction

The Placeholder grid component displays the placeholder as a grid. This component is based on
the [Placeholder.Grid](https://rsuitejs.com/components/placeholder/#grid-or-table) component.

## Main properties

The following general properties are available within the _Main_ tab:

| Name        | Type      | Description                       |
|:------------|:----------|:----------------------------------|
| Rows        | `number`  | The number of rows                |
| Columns     | `number`  | The number of columns             |
| Row height  | `number`  | The height of the row             |
| Row spacing | `number`  | The spacing between rows          |
| Active      | `boolean` | Whether the placeholder is active |
