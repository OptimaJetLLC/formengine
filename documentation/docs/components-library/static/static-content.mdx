## Introduction

Static content represents a component a text element that displays static text content within an HTML span tag. This component is typically
used display labels or present any other text that does not require user interaction or dynamic updates.

This component can be used to add plain text to your form or customized to include HTML, change colors, and so on. The following introduces
and describes properties and options presented for the static content component customization.

## Main properties

The following general properties are available within the _Main_ tab:

| Name       | Type      | Description                                                                                                                                                          |
|:-----------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Content    | `string`  | Specifies the content to be displayed within the component. This property is required and can accept both plain text and HTML code (in case _Allow HTML_ is enabled) |
| Allow HTML | `boolean` | If set to _true_, enables you to use HTML for your content (e.g., use `<h1>` tags to convert the content to a header)                                                |
