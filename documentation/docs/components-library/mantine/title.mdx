## Introduction

The Title component renders headings (h1–h6) with consistent styling. It is commonly used for section titles, form headings, and
page structure. The component maps the order property to semantic HTML heading levels and supports Mantine theming.

The Title component is based on [Mantine Title](https://mantine.dev/core/title/). It is included within the following
NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

The Title component can be styled and configured to fit specific design and functionality requirements by using various properties
that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name       | Type      | Description                                                                                  |
|:-----------|:----------|:---------------------------------------------------------------------------------------------|
| Children   | `string`  | The heading text (data-bound)                                                               |
| Order      | `1 \| 2 \| 3 \| 4 \| 5 \| 6`                                                                | Semantic heading level (1 = h1, 6 = h6); default: `4`    |
| Size       | `string`  | Override font size (e.g. Mantine size or CSS value)                                         |
| Line clamp | `number`  | Number of lines before clamping with ellipsis                                                |
| Text wrap  | `'wrap' \| 'nowrap' \| 'balance'`                                                            | Text wrapping behavior                                    |
