## Introduction

The MonthPickerInput component combines an input with a month picker popover. Variants include single month, month range, and
multiple months. The component requires `@mantine/dates` and is based on [Mantine MonthPicker](https://mantine.dev/dates/month-picker/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Components covered

- **MtMonthPickerInput**: Single month selection with input.
- **MtMonthRangePickerInput**: Month range selection with input.
- **MtMonthMultiplePickerInput**: Multiple months selection with input.

## Differences between components

| Component                        | Selection type     | Value shape                     | Typical use case                                |
|:---------------------------------|:------------------|:--------------------------------|:------------------------------------------------|
| **MtMonthPickerInput**          | Single month      | `Date \| null`                  | Single month field with text input              |
| **MtMonthRangePickerInput**     | Month range       | `[Date, Date] \| null`          | Start/end month range with text input           |
| **MtMonthMultiplePickerInput**  | Multiple months   | `Date[]`                        | Choosing several months via input + popover     |

### MtMonthPickerInput

Input-based single-month picker for cases where a textual representation is required (for example, month input with format and
validation).

### MtMonthRangePickerInput

Range version that uses an input field to represent the span of months. Ideal for defining report or subscription periods.

### MtMonthMultiplePickerInput

Multiple-month input variant to select and display several months in a single control, using both text and popover.

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the input                                                                         |
| Value        | `Date \| null` (or range/multiple) | Selected month(s) (uncontrolled value)                          |
| Placeholder  | `string`  | Placeholder when no selection                                                              |
| Description  | `string`  | Helper text below the field                                                                  |
| Error        | `string`  | Error message; when set, applies error styling                                              |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the input                                    |
| Variant      | `'filled' \| 'default' \| 'unstyled'`                                                        | Visual variant                                       |
| Disabled     | `boolean` | Disables the input                                                                          |
| Clearable    | `boolean` | If `true`, allows clearing the selection                                                     |
| On change    | `event`   | Fired when the selection changes                                                            |
