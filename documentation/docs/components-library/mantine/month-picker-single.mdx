## Introduction

`MtMonthPicker` is the single-month variant of the Mantine month picker. It lets users pick one month/year combination.

This page describes the properties of the **MtMonthPicker** component. For other variants, see the
[MonthPicker overview](/components-library/mantine/month-picker).

## Main properties

The following general properties are available within the _Main_ tab:

| Name      | Type                                   | Description                           |
|:----------|:---------------------------------------|:--------------------------------------|
| Value     | `Date \| null`                         | Selected month (uncontrolled value)   |
| Min date  | `Date`                                 | Minimum selectable month              |
| Max date  | `Date`                                 | Maximum selectable month              |
| Size      | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the picker                    |
| Disabled  | `boolean`                              | Disables the picker                   |
| On change | `event`                                | Fired when the selected month changes |

Additional configuration (columns, locale, formats, levels, etc.) is inherited from Mantine `MonthPicker`.
