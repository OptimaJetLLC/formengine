## Introduction

The NativeSelect component renders a native HTML `<select>` element with Mantine styling. It is lighter than the combobox-based
Select and is suitable when a simple dropdown without search is needed. The component is based on [Mantine NativeSelect](https://mantine.dev/core/select/) (native select variant).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the select                                                                        |
| Value        | `string`  | Selected value (uncontrolled value)                                                          |
| Data         | `array`   | Options (e.g. `[{ value: 'a', label: 'Option A' }, ...]`)                                    |
| Placeholder  | `string`  | Placeholder when no value selected                                                         |
| Description  | `string`  | Helper text below the field                                                                 |
| Error        | `string`  | Error message; when set, applies error styling                                             |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the select                                   |
| Variant      | `'filled' \| 'default' \| 'unstyled'`                                                        | Visual variant                                       |
| Disabled     | `boolean` | Disables the select                                                                         |
| On change    | `event`   | Fired when the value changes                                                                |
