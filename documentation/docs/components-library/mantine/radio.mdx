## Introduction

The Radio component represents a single option in a radio group. It is used together with MtRadioGroup for single-selection
choices. The component is based on [Mantine Radio](https://mantine.dev/core/radio/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name          | Type      | Description                                                                                  |
|:--------------|:----------|:---------------------------------------------------------------------------------------------|
| Label         | `string`  | Text displayed next to the radio                                                            |
| Value         | `string`  | Value of this option (when used inside RadioGroup)                                           |
| Label position| `'left' \| 'right'` | Position of the label relative to the radio                                    |
| Description   | `string`  | Helper text below the option                                                                |
| Size          | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the radio                                      |
| Color         | `string`  | Mantine theme color when selected                                                           |
| Disabled      | `boolean` | Disables the radio                                                                          |
