## Introduction

`MtYearPicker` is the single-year variant of the year picker. It focuses on selecting one specific year.

This page describes the properties of the **MtYearPicker** component. For other variants, see the
[YearPicker overview](/components-library/mantine/year-picker).

## Main properties

The following general properties are available within the _Main_ tab:

| Name      | Type                                   | Description                          |
|:----------|:---------------------------------------|:-------------------------------------|
| Value     | `Date \| null`                         | Selected year (uncontrolled value)   |
| Min date  | `Date`                                 | Minimum selectable year              |
| Max date  | `Date`                                 | Maximum selectable year              |
| Size      | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the picker                   |
| Disabled  | `boolean`                              | Disables the picker                  |
| On change | `event`                                | Fired when the selected year changes |

Additional configuration (columns, locale, formats, levels, etc.) is inherited from Mantine `YearPicker`.
