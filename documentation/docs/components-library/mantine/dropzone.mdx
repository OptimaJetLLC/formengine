## Introduction

The Dropzone component provides a dedicated area where users can drop files or click to select them. It supports accept types,
multiple files, and max size. It requires the optional package `@mantine/dropzone`. The component is based on
[Mantine Dropzone](https://mantine.dev/x/dropzone/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Accept       | `array`   | Accepted MIME types or extensions                                                           |
| Multiple     | `boolean` | If `true`, allows multiple files                                                          |
| Max size     | `number`  | Maximum file size in bytes                                                                  |
| On drop      | `event`   | Fired when files are dropped or selected                                                    |
| Disabled     | `boolean` | Disables the dropzone                                                                      |
