## Introduction

The Container component provides a responsive container to center and constrain content width. It is commonly used as a top-level wrapper
for page content to ensure proper alignment, responsive behavior, and consistent spacing across different screen sizes. The component
follows Mantine layout patterns with configurable size and strategy.

The Container component is based on [Mantine Container](https://mantine.dev/core/container/). It is included within the following
NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

The Container component can be styled and configured to fit specific design and functionality requirements by using various properties
that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name     | Type      | Description                                                                                  |
|:---------|:----------|:---------------------------------------------------------------------------------------------|
| Children | `node`    | Content inside the container                                                                |
| Fluid    | `boolean` | If `true`, the container has no max-width and stretches full width (default: `false`)       |
| Size     | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Responsive size (default: `'md'`)                          |
| Strategy | `'block' \| 'grid'`                                                                         | Layout strategy; form builder default uses flex column and gap (default: `'block'`) |
