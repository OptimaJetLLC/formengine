## Introduction

The Divider component renders a horizontal or vertical line to separate content. It can optionally display a label in the center or
on the left/right. The component is based on [Mantine Divider](https://mantine.dev/core/divider/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name            | Type      | Description                                                                                  |
|:----------------|:----------|:---------------------------------------------------------------------------------------------|
| Label           | `string`  | Optional text displayed on the divider                                                       |
| Label position  | `'left' \| 'center' \| 'right'`                                                             | Position of the label (default: `'center'`)             |
| Orientation    | `'horizontal' \| 'vertical'`                                                                | Orientation of the line (default: `'horizontal'`)      |
| Variant         | `'solid' \| 'dashed' \| 'dotted'`                                                            | Line style (default: `'solid'`)                        |
| Size            | `string`  | Thickness of the line (e.g. Mantine size or CSS value)                                       |
| Color           | `string`  | Color of the line                                                                            |
