## Introduction

`MtMonthMultiplePickerInput` is the multiple-month variant of the month picker input. It provides a text field and popover to select
several months independently.

This page describes the properties of the **MtMonthMultiplePickerInput** component. For other variants, see the
[MonthPickerInput overview](/components-library/mantine/month-picker-input).

## Main properties

The following general properties are available within the _Main_ tab:

| Name        | Type                                   | Description                                    |
|:------------|:---------------------------------------|:-----------------------------------------------|
| Label       | `string`                               | Label for the input                            |
| Value       | `Date[]`                               | Array of selected months                       |
| Placeholder | `string`                               | Placeholder when no selection                  |
| Description | `string`                               | Helper text displayed below the input          |
| Error       | `string`                               | Error message; when set, applies error styling |
| Size        | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the input                              |
| Variant     | `'filled' \| 'default' \| 'unstyled'`  | Visual variant                                 |
| Disabled    | `boolean`                              | Disables the input                             |
| Clearable   | `boolean`                              | If `true`, allows clearing the selection       |
| On change   | `event`                                | Fired when the selected months change          |

Additional configuration (columns, locale, formats, levels, etc.) is inherited from Mantine `MonthPickerInput`.
