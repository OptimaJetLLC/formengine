## Introduction

The Label component renders a form label that can be associated with form controls. It supports required indicator and size. The
component is based on [Mantine Input.Label](https://mantine.dev/core/input/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name     | Type      | Description                                                                                  |
|:---------|:----------|:---------------------------------------------------------------------------------------------|
| Children | `string`  | The label text (data-bound)                                                                  |
| Size     | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the label text                                 |
| Required| `boolean` | If `true`, shows the required asterisk (default: `false`)                                   |
