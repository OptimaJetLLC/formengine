## Introduction

`MtYearRangePickerInput` is the range variant of the year picker input. It combines a text field and popover to select a start and end
year.

This page describes the properties of the **MtYearRangePickerInput** component. For other variants, see the
[YearPickerInput overview](/components-library/mantine/year-picker-input).

## Main properties

The following general properties are available within the _Main_ tab:

| Name        | Type                                   | Description                                    |
|:------------|:---------------------------------------|:-----------------------------------------------|
| Label       | `string`                               | Label for the input                            |
| Value       | `[Date, Date] \| null`                 | Selected year range (start and end)            |
| Placeholder | `string`                               | Placeholder when no selection                  |
| Description | `string`                               | Helper text displayed below the input          |
| Error       | `string`                               | Error message; when set, applies error styling |
| Size        | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the input                              |
| Variant     | `'filled' \| 'default' \| 'unstyled'`  | Visual variant                                 |
| Disabled    | `boolean`                              | Disables the input                             |
| Clearable   | `boolean`                              | If `true`, allows clearing the selection       |
| On change   | `event`                                | Fired when the selected range changes          |

Additional configuration (columns, locale, formats, levels, etc.) is inherited from Mantine `YearPickerInput`.
