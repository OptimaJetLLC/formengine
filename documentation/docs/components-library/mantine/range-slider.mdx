## Introduction

The RangeSlider component allows users to select a numeric range by dragging two thumbs along a track. It is useful for filters,
price ranges, or any min–max selection. The component is based on [Mantine RangeSlider](https://mantine.dev/core/slider/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the slider                                                                        |
| Value        | `[number, number]` | Current range as [min, max] (uncontrolled value)                              |
| Min          | `number`  | Minimum value                                                                               |
| Max          | `number`  | Maximum value                                                                               |
| Step         | `number`  | Step size                                                                                   |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the slider                                  |
| Disabled     | `boolean` | Disables the slider                                                                         |
| On change    | `event`   | Fired when the range changes                                                                |
