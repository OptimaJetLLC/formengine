## Introduction

`MtDateMultiplePickerInput` is the multiple-dates variant of the date picker input. It lets users select an arbitrary number of dates
using a text field and calendar popover.

This page describes the properties of the **MtDateMultiplePickerInput** component. For other variants, see the
[DatePickerInput overview](/components-library/mantine/date-picker-input).

## Main properties

The following general properties are available within the _Main_ tab:

| Name        | Type                                   | Description                                    |
|:------------|:---------------------------------------|:-----------------------------------------------|
| Label       | `string`                               | Label for the input                            |
| Value       | `Date[]`                               | Array of selected dates                        |
| Placeholder | `string`                               | Placeholder when no dates are selected         |
| Description | `string`                               | Helper text displayed below the input          |
| Error       | `string`                               | Error message; when set, applies error styling |
| Min date    | `Date`                                 | Minimum selectable date                        |
| Max date    | `Date`                                 | Maximum selectable date                        |
| Size        | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the input                              |
| Variant     | `'filled' \| 'default' \| 'unstyled'`  | Visual variant                                 |
| Disabled    | `boolean`                              | Disables the input                             |
| Clearable   | `boolean`                              | If `true`, allows clearing the selection       |
| On change   | `event`                                | Fired when the selected dates change           |

Additional configuration (columns, locale, formats, levels, etc.) is inherited from Mantine `DatePickerInput`.
