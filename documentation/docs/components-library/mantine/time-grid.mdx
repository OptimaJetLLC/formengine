## Introduction

The TimeGrid component displays a grid of time slots (e.g. in 24h or 12h format) for scheduling, booking, or time selection. You can
provide a custom list of times or a start/end range with an interval. The component requires `@mantine/dates` and is based on
[Mantine TimeGrid](https://mantine.dev/dates/time-grid/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name           | Type                                   | Description                                                                             |
|:---------------|:---------------------------------------|:----------------------------------------------------------------------------------------|
| Label          | `string`                               | Label for the time grid                                                                 |
| Description    | `string`                               | Helper text below the field                                                             |
| Error          | `string`                               | Error message; when set, applies error styling                                          |
| Value          | `string`                               | Selected time value (e.g. `"HH:mm"`) (data-bound)                                       |
| Data           | `array`                                | Custom list of time strings in 24h format; if empty, times are generated from start/end |
| Start time     | `string`                               | Start of the time range (e.g. `"00:00"`) (default: `"00:00"`)                           |
| End time       | `string`                               | End of the time range (e.g. `"23:59"`) (default: `"23:59"`)                             |
| Format         | `'12h' \| '24h'`                       | Time display format (default: `'24h'`)                                                  |
| With seconds   | `boolean`                              | If `true`, includes seconds in the time values (default: `false`)                       |
| Allow deselect | `boolean`                              | If `true`, allows clearing the selection (default: `false`)                             |
| Min time       | `string`                               | Minimum selectable time                                                                 |
| Max time       | `string`                               | Maximum selectable time                                                                 |
| Size           | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the grid items                                                                  |
| Disabled       | `boolean`                              | Disables the time grid (default: `false`)                                               |
| On change      | `event`                                | Fired when the selected time changes                                                    |
