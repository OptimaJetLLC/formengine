## Introduction

The Tiptap component provides a rich text editor (WYSIWYG) with formatting toolbar and support for headings, lists, links, and more.
It requires the optional package `@mantine/tiptap` and is based on [Mantine Tiptap](https://mantine.dev/x/tiptap/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name        | Type      | Description                                          |
|:------------|:----------|:-----------------------------------------------------|
| Content     | `string`  | Initial or controlled HTML/content (data-bound)      |
| Placeholder | `string`  | Placeholder when editor is empty                     |
| Editable    | `boolean` | If `true`, the content is editable (default: `true`) |
| On change   | `event`   | Fired when the content changes                       |
