## Introduction

The DateTimePicker component allows users to select both a date and a time. It combines date and time selection in one control. The
component requires `@mantine/dates` and is based on [Mantine DatePicker](https://mantine.dev/dates/date-picker/) and time handling.

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Value        | `Date \| null` | Selected date and time (uncontrolled value)                                          |
| Min date     | `Date`    | Minimum selectable date/time                                                                |
| Max date     | `Date`    | Maximum selectable date/time                                                                |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the control                                  |
| Disabled     | `boolean` | Disables the picker                                                                        |
| On change    | `event`   | Fired when the value changes                                                                |
