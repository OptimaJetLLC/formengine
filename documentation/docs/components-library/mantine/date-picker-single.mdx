## Introduction

`MtDatePicker` is the single-date variant of the Mantine date picker. It lets users choose exactly one day from the calendar and is the
simplest option for date fields such as birthdays, due dates, or any single calendar date.

This page describes the properties of the **MtDatePicker** component. For other variants, see the
[DatePicker overview](/components-library/mantine/date-picker).

## Main properties

The following general properties are available within the _Main_ tab:

| Name       | Type              | Description                                   |
|:-----------|:------------------|:----------------------------------------------|
| Value      | `Date \| null`    | Selected date (uncontrolled value)            |
| Min date   | `Date`            | Minimum selectable date                       |
| Max date   | `Date`            | Maximum selectable date                       |
| Size       | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the calendar                 |
| Disabled   | `boolean`         | Disables the picker                           |
| On change  | `event`           | Fired when the date changes                   |

In addition, the component supports advanced calendar configuration (columns, locale, formats, levels, etc.) inherited from the
underlying Mantine `DatePicker`. Refer to the Mantine documentation for those options.
