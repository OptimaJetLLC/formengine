## Introduction

The ColorInput component combines a text input for hex (or other) color values with an optional color swatch and picker popover. It is
used for theme or style customization. The component is based on [Mantine ColorInput](https://mantine.dev/core/color-input/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the input                                                                         |
| Value        | `string`  | Current color value (e.g. hex) (uncontrolled value)                                          |
| Format       | `string`  | Color format (e.g. `'hex'`, `'rgba'`)                                                       |
| Description  | `string`  | Helper text below the field                                                                  |
| Error        | `string`  | Error message; when set, applies error styling                                               |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the input                                    |
| Disabled     | `boolean` | Disables the input                                                                          |
| Disallow input | `boolean` | If `true`, user cannot type; only picker can set value                                     |
| On change    | `event`   | Fired when the color changes                                                                |
