## Introduction

The Typography component provides consistent text styling and semantic HTML for displaying text content. It can render plain text or
HTML when allowed, and is commonly used for static content blocks, descriptions, and formatted text in forms. The component uses
Mantine Text and Typography under the hood.

The Typography component is based on [Mantine Text](https://mantine.dev/core/text/) and [Mantine Typography](https://mantine.dev/core/typography/). It is included within the following
NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

The Typography component can be styled and configured to fit specific design and functionality requirements by using various properties
that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name       | Type      | Description                                                                                  |
|:-----------|:----------|:---------------------------------------------------------------------------------------------|
| Content    | `string`  | The text content to display (data-bound)                                                    |
| Allow HTML | `boolean` | If `true`, content is rendered as HTML; otherwise as plain text (default: `false`)         |
