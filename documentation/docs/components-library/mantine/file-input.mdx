## Introduction

The FileInput component allows users to select files via a button or drag-and-drop. It can accept a single file or multiple files and
supports clear and value display. The component is based on [Mantine FileInput](https://mantine.dev/core/file-input/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the input                                                                         |
| Placeholder  | `string`  | Placeholder when no file selected                                                           |
| Description  | `string`  | Helper text below the field                                                                  |
| Error        | `string`  | Error message; when set, applies error styling                                               |
| Accept      | `string`  | Accepted file types (e.g. `'image/*'`, `'.pdf'`)                                            |
| Multiple    | `boolean` | If `true`, allows selecting multiple files                                                  |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the input                                    |
| Variant      | `'filled' \| 'default' \| 'unstyled'`                                                        | Visual variant                                       |
| Disabled     | `boolean` | Disables the input                                                                          |
| Clearable    | `boolean` | If `true`, shows clear button                                                               |
| On change    | `event`   | Fired when the file(s) change                                                               |
