## Introduction

The RadioGroup component groups radio options so the user can select a single value. It provides a shared label, description, and
error state. The component is based on [Mantine Radio.Group](https://mantine.dev/core/radio/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the group                                                                         |
| Description  | `string`  | Helper text below the group                                                                 |
| Error        | `string`  | Error message; when set, applies error styling                                              |
| Value        | `string`  | The selected value (uncontrolled value)                                                     |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the radio buttons                               |
| Children     | `node`    | Radio options (typically MtRadio)                                                           |
| On change    | `event`   | Fired when the selection changes                                                            |
