## Introduction

The Chip component displays a compact element that can represent a tag, filter, or choice. It can be checkable or removable. The
component is based on [Mantine Chip](https://mantine.dev/core/chip/). MtChipCheckboxGroup and MtChipRadioGroup use chips for
multi/single selection.

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Children     | `string`  | The label text of the chip                                                                  |
| Checked      | `boolean` | Checked state (when used as checkable)                                                      |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the chip                                    |
| Variant      | `string`  | Visual variant                                                                              |
| Disabled     | `boolean` | Disables the chip                                                                           |
| On change    | `event`   | Fired when checked state changes (checkable chips)                                          |
