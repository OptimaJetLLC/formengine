## Introduction

`MtDateMultiplePicker` is the multiple-dates variant of the Mantine date picker. It allows selecting any number of distinct dates and is
useful for scenarios like marking events, exceptions, or custom highlighted days.

This page describes the properties of the **MtDateMultiplePicker** component. For an overview of all date picker variants, see the
[DatePicker overview](/components-library/mantine/date-picker).

## Main properties

The following general properties are available within the _Main_ tab:

| Name       | Type        | Description                                  |
|:-----------|:------------|:---------------------------------------------|
| Value      | `Date[]`    | Array of selected dates                      |
| Min date   | `Date`      | Minimum selectable date                      |
| Max date   | `Date`      | Maximum selectable date                      |
| Size       | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the calendar              |
| Disabled   | `boolean`   | Disables the picker                          |
| On change  | `event`     | Fired when the list of dates changes         |

Advanced calendar configuration props (columns, locale, label formats, levels, etc.) are also supported via the underlying
Mantine `DatePicker` API.
