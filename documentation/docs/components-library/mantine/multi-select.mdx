## Introduction

The MultiSelect component allows users to select multiple options from a dropdown. Selected values are shown as tags or in a
compact list. The component is based on [Mantine MultiSelect](https://mantine.dev/core/multi-select/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the dropdown                                                                      |
| Value        | `array`   | Selected values (array of strings) (uncontrolled value)                                    |
| Data         | `array`   | Options (e.g. `[{ value: 'a', label: 'Option A' }, ...]`)                                    |
| Placeholder  | `string`  | Placeholder when nothing selected                                                           |
| Description  | `string`  | Helper text below the field                                                                  |
| Error        | `string`  | Error message; when set, applies error styling                                               |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the input                                    |
| Variant      | `'filled' \| 'default' \| 'unstyled'`                                                        | Visual variant                                       |
| Disabled     | `boolean` | Disables the dropdown                                                                       |
| Clearable    | `boolean` | If `true`, allows clearing the selection                                                    |
| Searchable   | `boolean` | If `true`, allows filtering by typing                                                       |
| Nothing found message | `string`  | Message when search has no results                                                 |
| On change    | `event`   | Fired when the selection changes                                                            |
