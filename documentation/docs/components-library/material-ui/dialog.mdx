## Introduction

The Dialog component creates modal overlay windows that prompt users to make decisions, enter information, or acknowledge important
messages. Dialogs are essential for creating focused user interactions without navigating away from the current context. The component
follows Material Design dialog guidelines with proper elevation, transitions, and accessibility features.

The Dialog component is based on [Material UI Dialog](https://mui.com/material-ui/react-dialog/). It is included within the following
NPM package: [@react-form-builder/components-material-ui](https://www.npmjs.com/package/@react-form-builder/components-material-ui).

The Dialog component can be configured to create various dialog types including alerts, confirmations, forms, and custom content displays.
It can be styled and customized to fit specific design and functionality requirements by using various properties that are presented and
described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name                    | Type                                   | Description                                                  | Default   |
|:------------------------|:---------------------------------------|:-------------------------------------------------------------|:----------|
| Open                    | `boolean`                              | Controls whether the dialog is visible                       | `false`   |
| Full screen             | `boolean`                              | If `true`, the dialog will be full screen                    | -         |
| Full width              | `boolean`                              | If `true`, the dialog stretches to its maximum width         | `false`   |
| Max width               | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Maximum width of the dialog                                  | `'md'`    |
| Scroll                  | `'paper' \| 'body'`                    | Determines the scroll container for the dialog content       | `'paper'` |
| Disable escape key down | `boolean`                              | If `true`, pressing the escape key will not close the dialog | -         |
| On close                | `event`                                | Event handler triggered when the dialog closes               | -         |
