## Introduction

The CircularProgress component displays a circular loading indicator for indeterminate or determinate progress. It is commonly used
to indicate loading states, progress of operations, or waiting periods in applications. The component follows Material Design guidelines
for progress indicators with smooth animations and visual feedback.

The CircularProgress component is based on [Material UI CircularProgress](https://mui.com/material-ui/react-progress/). It is included
within the following
NPM package: [@react-form-builder/components-material-ui](https://www.npmjs.com/package/@react-form-builder/components-material-ui).

The CircularProgress component can be styled and configured to fit specific design and functionality requirements by using various
properties that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name           | Type                                                                                   | Description                                                              |
|:---------------|:---------------------------------------------------------------------------------------|:-------------------------------------------------------------------------|
| Value          | `number`                                                                               | The value of the progress indicator for determinate variant (0 to 100)   |
| Thickness      | `number`                                                                               | The thickness of the circular progress in pixels                         |
| Variant        | `'determinate' \| 'indeterminate'`                                                     | The variant of the progress indicator                                    |
| Color          | `'primary' \| 'secondary' \| 'error' \| 'info' \| 'success' \| 'warning' \| 'inherit'` | The color of the component                                               |
| Disable shrink | `boolean`                                                                              | If `true`, the shrink animation is disabled (indeterminate variant only) |
