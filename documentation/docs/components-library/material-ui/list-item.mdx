## Introduction

The ListItem component represents a single item within a list, with support for text, icons, avatars, and actions. It is commonly
used as a building block for creating structured lists, navigation menus, and data displays. The component follows Material Design
guidelines for list items with proper spacing, interactive states, and visual hierarchy.

The ListItem component is based on [Material UI ListItem](https://mui.com/material-ui/api/list-item/). It is included within the following
NPM package: [@react-form-builder/components-material-ui](https://www.npmjs.com/package/@react-form-builder/components-material-ui).

The ListItem component can be styled and configured to fit specific design and functionality requirements by using various properties that
are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name            | Type      | Description                                                                                                            |
|:----------------|:----------|:-----------------------------------------------------------------------------------------------------------------------|
| Dense           | `boolean` | If `true`, compact vertical padding will be used                                                                       |
| Disable gutters | `boolean` | If true, disables the left and right padding                                                                           |
| Disable padding | `boolean` | If true, disables the default padding                                                                                  |
| Divider         | `boolean` | If `true`, a divider will be displayed at the bottom of the list item                                                  |
| Sx              | `object`  | The system prop that allows defining system overrides as well as additional CSS styles                                 |
