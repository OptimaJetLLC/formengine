## Introduction

The FormControlLabel component wraps form controls with labels for better accessibility and consistent styling. It is commonly used to
associate labels with checkboxes, radio buttons, switches, and other form controls, ensuring proper accessibility attributes and
consistent spacing. The component follows Material Design guidelines for form controls with proper label placement and interaction states.

The FormControlLabel component is based on [Material UI FormControlLabel](https://mui.com/material-ui/api/form-control-label/). It is
included within the following NPM
package: [@react-form-builder/components-material-ui](https://www.npmjs.com/package/@react-form-builder/components-material-ui).

The FormControlLabel component can be styled and configured to fit specific design and functionality requirements by using various
properties that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name               | Type                                    | Description                                                           |
|:-------------------|:----------------------------------------|:----------------------------------------------------------------------|
| Control            | `ReactElement`                          | The form control component (e.g., Checkbox, Radio, Switch)            |
| Value              | `any`                                   | The value of the component                                            |
| Checked            | `boolean`                               | If `true`, the component appears selected (for controlled components) |
| Disabled           | `boolean`                               | If `true`, the component will be disabled                             |
| Disable typography | `boolean`                               | If true, disables typography styling for the label                    |
| label              | `string \| ReactNode`                   | The label text or content                                             |
| Label placement    | `'end' \| 'start' \| 'top' \| 'bottom'` | The position of the label relative to the control (default: `'end'`)  |
