_November 24, 2026_

## Overview

FormEngine 12.1.0 puts the full monorepo on
[GitHub](https://github.com/OptimaJetLLC/formengine). Community packages, including
[FormEngine Core](/formengine-core/), stay under MIT. Designer and other commercial packages use the
[FormEngine EULA](https://formengine.io/eula/) (source-available). Details are in
[LICENSE.md](https://github.com/OptimaJetLLC/formengine/blob/master/LICENSE.md) and
[EULA.md](https://github.com/OptimaJetLLC/formengine/blob/master/EULA.md).
File product bugs, features, and questions as
[GitHub issues](https://github.com/OptimaJetLLC/formengine/issues).

The designer again scrolls the component tree to the selected canvas component. RSuite Uploader and Calendar pass updated axe-core label
checks. The toolchain pins Node.js 26.13.1 for the November 2026 security fixes.

### Why update

- Clone or browse the public monorepo and check package licenses in
  [LICENSE.md](https://github.com/OptimaJetLLC/formengine/blob/master/LICENSE.md).
- Open product issues on [GitHub](https://github.com/OptimaJetLLC/formengine/issues).
- Take the designer tree scroll fix, Uploader/Calendar accessibility fixes, and the Node.js 26.13.1 security pin.

## Migration

- Open bugs, feature requests, and questions on
  [GitHub Issues](https://github.com/OptimaJetLLC/formengine/issues) using the Bug report, Feature request, or Question templates.
- For pull requests, follow the
  [contribution guide](https://github.com/OptimaJetLLC/formengine/blob/master/CONTRIBUTION.md): match repository conventions, run
  `npm run check-all`, and sign the [CLA](https://github.com/OptimaJetLLC/formengine/blob/master/CLA.md). External contributors must sign;
  CI fails unsigned pull requests.
- Check the package license before you redistribute or contribute. MIT packages are listed in
  [LICENSE.md](https://github.com/OptimaJetLLC/formengine/blob/master/LICENSE.md). Designer and other commercial packages use the
  [FormEngine EULA](https://formengine.io/eula/).

## Changelog

### Features

- Published the FormEngine monorepo on GitHub under MIT and FormEngine EULA package licenses, with CLA and contribution guides.

### Enhancements

- Grouped Dependabot security updates into one weekly pull request.

### Bug fixes

- Restored component tree auto-scroll when selecting a component on the designer canvas.
- Fixed RSuite Uploader and Calendar accessible names for axe-core 4.14 `label-content-name-mismatch` checks.
- Fixed root typecheck failing when sample apps are present without workspace installs.

### Security

- Bumped the monorepo Node.js pin from `26.13.0` to `26.13.1` (November 2026 Node.js security releases).

### Chore

- Bumped Biome to `2.6.6` and applied formatting.
- Bumped TypeScript to `5.9.3`.
- Bumped Playwright to `1.65`, CTRF to `0.2`, and monocart-reporter to `2.15`.
- Bumped `skia-canvas` from `3.0.8` to `4.0.0`.
- Applied the Dependabot patch dependency group upgrades.
- Tightened tests that still used globals and expanded `onFormDataChange` coverage.
