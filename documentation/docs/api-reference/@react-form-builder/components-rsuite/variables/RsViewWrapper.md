# Variable: RsViewWrapper

> `const` **RsViewWrapper**: [`FormViewerWrapper`](../../core/type-aliases/FormViewerWrapper.md)

Combined RSuite viewer wrapper that nests theme and localization providers.
Use this for FormBuilder, and for FormViewer when you need light/dark theming
(for example with BuilderThemeProvider). For locale and RTL only, use [RsLocalizationWrapper](RsLocalizationWrapper.md).

## Param

**props**

the FormViewerWrapper props.

## Returns

the wrapped components with theme and localization settings applied.
