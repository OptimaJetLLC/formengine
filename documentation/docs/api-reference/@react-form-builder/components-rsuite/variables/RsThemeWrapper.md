# Variable: RsThemeWrapper

> `const` **RsThemeWrapper**: [`FormViewerWrapper`](../../core/type-aliases/FormViewerWrapper.md)

Wrapper that applies the RSuite theme from BuilderThemeProvider.
Prefer [RsViewWrapper](RsViewWrapper.md) when you also need localization.
When nested under another CustomProvider, inherits locale and other parent settings.

## Param

**props**

the FormViewerWrapper props.

## Returns

the wrapped components with the RSuite theme applied.
