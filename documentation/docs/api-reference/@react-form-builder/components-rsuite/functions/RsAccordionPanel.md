# Function: RsAccordionPanel()

> **RsAccordionPanel**(`props`): `Element`

A single panel for use inside RsAccordion (RSuite Panel in an accordion group).
In builder mode the panel stays expanded and non-collapsible so its contents remain editable.

## Parameters

### props

[`RsAccordionPanelProps`](../interfaces/RsAccordionPanelProps.md)

the component props.

## Returns

`Element`

the React element.
