# Function: hasOtherInstanceOfType()

> **hasOtherInstanceOfType**(`root`, `component`): `boolean`

Returns true when another component of the same type already exists under the root.

## Parameters

### root

[`ComponentData`](../classes/ComponentData.md)

the form component tree root.

### component

[`ComponentData`](../classes/ComponentData.md)

the component being checked.

## Returns

`boolean`

true when another instance of the same type exists, false otherwise.
