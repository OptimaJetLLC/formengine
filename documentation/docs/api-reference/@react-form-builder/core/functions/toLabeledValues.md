# Function: toLabeledValues()

> **toLabeledValues**(`items`, `upper`): `object`[]

## Parameters

• **items**: `string`[] \| [`LabeledValue`](../interfaces/LabeledValue.md)[]

the array of elements.

• **upper**: `boolean` = `true`

if true, the first character in [LabeledValue.label](../interfaces/LabeledValue.md#label) will be capitalized.

## Returns

`object`[]

the array of [LabeledValue](../interfaces/LabeledValue.md) elements.
