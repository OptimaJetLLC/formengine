# Function: isPromise()

> **isPromise**\<`T`\>(`value`): `value is Promise<T>`

Type predicate, asserts that the value is a Promise. **Internal use only.**

## Type Parameters

• **T** = `any`

## Parameters

• **value**: `any`

the value.

## Returns

`value is Promise<T>`

true if the value is a Promise, false otherwise.
