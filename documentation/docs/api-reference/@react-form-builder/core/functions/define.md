# Function: define()

> **define**\<`T`\>(`component`, `displayName`?): [`Definer`](../classes/Definer.md)\<`T`\>

Static method to create an instance of the component's metadata builder class.

## Type Parameters

• **T** *extends* `object`

## Parameters

• **component**: `ComponentType`\<`T`\>

the React component.

• **displayName?**: `string`

the display name for the anonymous component.

## Returns

[`Definer`](../classes/Definer.md)\<`T`\>

the instance of the [Definer](../classes/Definer.md) class.
