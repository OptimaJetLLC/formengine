## Changelog

### Update instructions

Update all packages to version **8.0.0**.

- The `displayName` property of a component is no longer overridden, so you cannot rely on it when filtering components. Instead, you can
  use the [typeName](/api-reference/@react-form-builder/core/type-aliases/DefinerData#typename) property. You can also use
  the [type](/api-reference/@react-form-builder/core/classes/Model#type) property to get the component type after the component has been
  assembled via the [build](/api-reference/@react-form-builder/core/interfaces/Definer#build) method.

  Example of filtering prior to version 8.0.0:

  ```typescript
  components.filter(component => {
    component.data.component.displayName !== 'RsTimePicker'
  })
  ```

  Example of filtering after version 8.0.0:

  ```typescript
  components.filter(component => {
    return component.data.typeName !== 'RsTimePicker'
  })
  ```
