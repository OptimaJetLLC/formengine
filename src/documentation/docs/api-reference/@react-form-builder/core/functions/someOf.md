> **someOf**\<`U`\>(...`values`): [`SomeOfBuilder`](../classes/SomeOfBuilder.md)\<`U`\>

## Type Parameters

• **U** *extends* `string` \| `number`

## Parameters

• ...**values**: `U`[]

the possible values for the property.

## Returns

[`SomeOfBuilder`](../classes/SomeOfBuilder.md)\<`U`\>
