# Interface: TemplateProps

The template component properties.

## Extends

- `Omit`\<[`EmbeddedFormProps`](EmbeddedFormProps.md), `"formName"`\>

## Properties

### disabled?

> `optional` **disabled**: `boolean`

If true, the embedded form is disabled.

#### Inherited from

`Omit.disabled`

***

### options?

> `optional` **options**: `any`

The additional options for loading the embedded form ([FormViewerProps.formOptions](FormViewerProps.md#formoptions)).

#### Inherited from

`Omit.options`

***

### readOnly?

> `optional` **readOnly**: `boolean`

If true, the embedded form is read-only.

#### Inherited from

`Omit.readOnly`

***

### storeDataInParentForm?

> `optional` **storeDataInParentForm**: `boolean`

If false, nested form data show as nested object, true otherwise.

#### Inherited from

`Omit.storeDataInParentForm`
