# Roadmap

On this page you can see what tasks are planned to improve FormEngine. As well as tasks that may be done, but are not yet planned.

The FormEngine team constantly makes sure that NPM packages are updated and do not contain vulnerable dependencies. The team tries to update
vulnerable packages as quickly as possible if patches are available for those packages.

:::info feature request

If you want to add a feature to our roadmap - please open an issue in
our [GitHub repository](https://github.com/optimajet/formengine/issues).

:::
