## Introduction

This component provides an appearance for the modal window and is based on components from the
[RSuite library](https://rsuitejs.com/components/modal). There are three slots inside the component: the header, the body, and the footer
of the modal window. You can add the necessary child components to these slots. This component is a part
of [@react-form-builder/components-rsuite](https://www.npmjs.com/package/@react-form-builder/components-rsuite).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                       |
|:-------------|:----------|:--------------------------------------------------|
| Close button | `boolean` | Display close button                              |
