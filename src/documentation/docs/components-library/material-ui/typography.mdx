## Introduction

The Typography component provides consistent text styling and semantic HTML elements for displaying text content. It is commonly used for
headings, paragraphs, captions, and other text elements throughout an application. The component ensures visual consistency and proper
semantic structure with Material Design typography.

The Typography component is based on [Material UI Typography](https://mui.com/material-ui/react-typography/). It is included within the
following NPM package: [@react-form-builder/components-material-ui](https://www.npmjs.com/package/@react-form-builder/components-material-ui).

The Typography component can be styled and configured to fit specific design and functionality requirements by using various properties
that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name          | Type                                                                                                                                                   | Description                                                          |
|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------------------------|
| Content       | `string \| ReactNode`                                                                                                                                  | The text content to display                                          |
| Variant       | `'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6' \| 'subtitle1' \| 'subtitle2' \| 'body1' \| 'body2' \| 'caption' \| 'button' \| 'overline' \| 'inherit'` | The typography variant to use                                        |
| Color         | `'initial' \| 'inherit' \| 'primary' \| 'secondary' \| 'textPrimary' \| 'textSecondary' \| 'error' \| 'warning' \| 'info' \| 'success'`                | The color of the text                                                |
| Alignment     | `'inherit' \| 'left' \| 'center' \| 'right' \| 'justify'`                                                                                              | The text alignment                                                   |
| No wrap       | `boolean`                                                                                                                                              | If `true`, the text will not wrap and will overflow with an ellipsis |
| Gutter bottom | `boolean`                                                                                                                                              | If `true`, the text will have a bottom margin                        |
