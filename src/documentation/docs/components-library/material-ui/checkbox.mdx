## Introduction

The Checkbox component allows users to select one or multiple options from a set. It is commonly used for binary choices, agreement
to terms, or selecting multiple items from a list. The component provides a visual representation of a checked/unchecked state with
Material Design styling.

The Checkbox component is based on [Material UI Checkbox](https://mui.com/material-ui/react-checkbox/). It is included within the following
NPM package: [@react-form-builder/components-material-ui](https://www.npmjs.com/package/@react-form-builder/components-material-ui).

The Checkbox component can be styled and configured to fit specific design and functionality requirements by using various properties that
are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name     | Type      | Description                                                                                          |
|:---------|:----------|:-----------------------------------------------------------------------------------------------------|
| Label    | `string`  | Text that is displayed next to the checkbox                                                          |
| Checked  | `boolean` | Sets the initial checked state of the checkbox                                                       |
| Color    | `string`  | Sets the color of the checkbox (e.g., `primary`, `secondary`, `success`, `error`, `info`, `warning`) |
| Disabled | `boolean` | Disables the checkbox, making it non-interactive                                                     |
| Size     | `choice`  | Sets the size of the checkbox (`small`, `medium`, `large`)                                           |
