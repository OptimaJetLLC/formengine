## Introduction

The DialogContentText component provides styled text content optimized for use within dialog windows. It follows Material Design typography
guidelines for dialog text, ensuring proper readability, spacing, and visual hierarchy for textual content in modal interfaces. The
component applies appropriate typography styles that work well within the constrained space of dialog containers.

The DialogContentText component is based on [Material UI DialogContentText](https://mui.com/material-ui/api/dialog-content-text/). It is
included within the following NPM
package: [@react-form-builder/components-material-ui](https://www.npmjs.com/package/@react-form-builder/components-material-ui).

The DialogContentText component can be configured to display various text content with customizable typography properties to fit specific
design requirements.

## Main properties

The following general properties are available within the _Main_ tab:

| Name          | Type                                                                                                                                                   | Description                                                                              | Default                 |
|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------|:------------------------|
| Children      | `string`                                                                                                                                               | The text content displayed in the dialog                                                 | `'Dialog content text'` |
| Variant       | `'body1' \| 'body2' \| 'button' \| 'caption' \| 'h1' \| 'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6' \| 'inherit' \| 'overline' \| 'subtitle1' \| 'subtitle2'` | The typography variant to use                                                            |                         |
| Color         | `'primary' \| 'secondary' \| 'error' \| 'info' \| 'success' \| 'warning' \| 'textPrimary' \| 'textSecondary' \| 'inherit'`                             | The color of the link                                                                    |                         |
| Alignment     | `'inherit' \| 'left' \| 'center' \| 'right' \| 'justify'`                                                                                              | Text alignment                                                                           |                         |
| No wrap       | `boolean`                                                                                                                                              | If true, the text will not wrap, but instead will truncate with a text overflow ellipsis |                         |
| Gutter bottom | `boolean`                                                                                                                                              | If true, the text will have a bottom margin                                              |                         |
