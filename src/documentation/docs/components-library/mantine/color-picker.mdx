## Introduction

The ColorPicker component displays a color picker UI (e.g. hue/saturation and optional alpha) and can show preset swatches. It is
used when you need full color selection without a text input. The component is based on [Mantine ColorPicker](https://mantine.dev/core/color-picker/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Value        | `string`  | Current color value (uncontrolled value)                                                     |
| Format       | `string`  | Color format (e.g. `'hex'`, `'rgba'`)                                                       |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the picker                                  |
| Full width   | `boolean` | If `true`, picker stretches to container width                                             |
| With swatches | `boolean` | If `true`, shows color swatches                                                            |
| On change    | `event`   | Fired when the color changes                                                                |
