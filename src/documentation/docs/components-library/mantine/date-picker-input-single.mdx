## Introduction

`MtDatePickerInput` is the single-date variant of the Mantine date picker input. It renders a text input that shows a formatted date and
opens a calendar popover when activated.

This page describes the properties of the **MtDatePickerInput** component. For other variants, see the
[DatePickerInput overview](/components-library/mantine/date-picker-input).

## Main properties

The following general properties are available within the _Main_ tab:

| Name        | Type                                   | Description                                    |
|:------------|:---------------------------------------|:-----------------------------------------------|
| Label       | `string`                               | Label for the input                            |
| Value       | `Date \| null`                         | Selected date (uncontrolled value)             |
| Placeholder | `string`                               | Placeholder when no date is selected           |
| Description | `string`                               | Helper text displayed below the input          |
| Error       | `string`                               | Error message; when set, applies error styling |
| Min date    | `Date`                                 | Minimum selectable date                        |
| Max date    | `Date`                                 | Maximum selectable date                        |
| Size        | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | Size of the input                              |
| Variant     | `'filled' \| 'default' \| 'unstyled'`  | Visual variant                                 |
| Disabled    | `boolean`                              | Disables the input                             |
| Clearable   | `boolean`                              | If `true`, allows clearing the selection       |
| On change   | `event`                                | Fired when the date changes                    |

Additional calendar configuration props (columns, locale, formats, levels, etc.) are inherited from Mantine `DatePickerInput`.
