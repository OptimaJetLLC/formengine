## Introduction

The CheckboxGroup component wraps multiple checkboxes with a shared label, description, and error state. It is used when you need
several related checkboxes that act as a single form field. The component is based on [Mantine Checkbox.Group](https://mantine.dev/core/checkbox/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the group                                                                         |
| Description  | `string`  | Helper text below the group                                                                 |
| Error        | `string`  | Error message; when set, applies error styling                                              |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the checkboxes                                 |
| Children     | `node`    | Checkbox options (typically MtCheckbox or similar)                                          |
