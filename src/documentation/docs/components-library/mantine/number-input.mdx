## Introduction

The NumberInput component is used for numeric input with optional increment/decrement controls. It supports min, max, step, and
decimal precision. The component is based on [Mantine NumberInput](https://mantine.dev/core/number-input/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the input                                                                         |
| Value        | `number \| string` | Current value (uncontrolled value)                                                |
| Placeholder  | `string`  | Placeholder when empty                                                                      |
| Description  | `string`  | Helper text below the field                                                                  |
| Error        | `string`  | Error message; when set, applies error styling                                               |
| Min          | `number`  | Minimum allowed value                                                                       |
| Max          | `number`  | Maximum allowed value                                                                       |
| Step         | `number`  | Step for increment/decrement                                                                |
| Decimal scale| `number`  | Number of decimal places                                                                    |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the input                                    |
| Variant      | `'filled' \| 'default' \| 'unstyled'`                                                        | Visual variant                                       |
| Disabled     | `boolean` | Disables the input                                                                          |
| On change    | `event`   | Fired when the value changes                                                                |
