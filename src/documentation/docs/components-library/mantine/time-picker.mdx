## Introduction

The TimePicker component displays a time selection UI (e.g. dropdown or grid of time options). It is used when you need to pick a
time with a consistent step (e.g. every 15 minutes). The component requires `@mantine/dates` and is based on
[Mantine TimeInput](https://mantine.dev/dates/time-input/) and related date/time APIs.

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Value        | `string \| Date` | Selected time (uncontrolled value)                                                   |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the picker                                  |
| Disabled     | `boolean` | Disables the picker                                                                        |
| On change    | `event`   | Fired when the time changes                                                                 |
