## Introduction

The Slider component allows users to select a single numeric value by dragging a thumb along a track. It supports min, max, step,
and marks. The component is based on [Mantine Slider](https://mantine.dev/core/slider/).

It is included within the following NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

## Main properties

The following general properties are available within the _Main_ tab:

| Name         | Type      | Description                                                                                  |
|:-------------|:----------|:---------------------------------------------------------------------------------------------|
| Label        | `string`  | Label for the slider                                                                        |
| Value        | `number`  | Current value (uncontrolled value)                                                           |
| Min          | `number`  | Minimum value (default: `0`)                                                                |
| Max          | `number`  | Maximum value (default: `100`)                                                              |
| Step         | `number`  | Step size                                                                                   |
| Size         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | Size of the slider                                  |
| Disabled     | `boolean` | Disables the slider                                                                         |
| On change    | `event`   | Fired when the value changes                                                                |
