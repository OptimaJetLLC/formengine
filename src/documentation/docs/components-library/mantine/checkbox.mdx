## Introduction

The Checkbox component allows users to select one or multiple options from a set. It is commonly used for binary choices, agreement
to terms, or selecting multiple items from a list. The component provides a visual representation of a checked/unchecked state with
Mantine styling.

The Checkbox component is based on [Mantine Checkbox](https://mantine.dev/core/checkbox/). It is included within the following
NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

The Checkbox component can be styled and configured to fit specific design and functionality requirements by using various properties
that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name          | Type      | Description                                                                                  |
|:--------------|:----------|:---------------------------------------------------------------------------------------------|
| Label         | `string`  | Text displayed next to the checkbox                                                          |
| Checked       | `boolean` | Sets the initial checked state (uncontrolled value)                                          |
| Indeterminate | `boolean` | If `true`, shows indeterminate state                                                        |
| Label position| `'left' \| 'right'` | Position of the label relative to the checkbox                                    |
| Description   | `string`  | Helper text below the checkbox                                                               |
| Size          | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | The size of the checkbox                              |
| Color         | `string`  | Mantine theme color or CSS color when checked                                                |
| Variant       | `'filled' \| 'outline'`                                                                      | The visual variant                                    |
| Disabled      | `boolean` | Disables the checkbox                                                                       |
| On change     | `event`   | Fired when the checked state changes                                                         |
