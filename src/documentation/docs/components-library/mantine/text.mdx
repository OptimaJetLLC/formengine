## Introduction

The Text component is used for displaying body text with consistent styling. It supports size, color, gradient, line clamp, and
truncation options. The component is based on Mantine Text and is suitable for paragraphs, captions, and inline text.

The Text component is based on [Mantine Text](https://mantine.dev/core/text/). It is included within the following
NPM package: [@react-form-builder/components-mantine](https://www.npmjs.com/package/@react-form-builder/components-mantine).

The Text component can be styled and configured to fit specific design and functionality requirements by using various properties
that are presented and described below.

## Main properties

The following general properties are available within the _Main_ tab:

| Name      | Type      | Description                                                                                  |
|:----------|:----------|:---------------------------------------------------------------------------------------------|
| Children  | `string`  | The text content to display (data-bound)                                                    |
| Variant   | `'text' \| 'gradient'`                                                                      | The text variant                                                                 |
| Size      | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                       | The font size                                      |
| Inherit   | `boolean` | If `true`, inherits font size from parent                                                   |
| Inline    | `boolean` | If `true`, renders as inline element                                                        |
| Line clamp| `number`  | Number of lines before clamping with ellipsis                                                |
| Span      | `boolean` | If `true`, renders as a span                                                                 |
| Truncate  | `'start' \| 'end'`                                                                          | Truncates text at start or end with ellipsis        |
