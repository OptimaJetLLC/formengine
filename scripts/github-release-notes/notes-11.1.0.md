_October 9, 2026_

## Overview

FormEngine 11.1.0 is a maintenance release. It bumps product, tooling, and documentation dependencies on top of 11.0.0. There are no new features and no form JSON migration.

### Why update

* Pick up the dependency and security bumps listed below.

## Changelog
