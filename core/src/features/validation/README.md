# Валидация

## Используемые библиотеки

* Formik (https://formik.org/) - обработка форм
* yup (https://www.npmjs.com/package/yup) - схемы валидации

## Принципы работы

На секции с валидацией (на секции с полем) мы будем задавать правила валидации. Правила (схемы) нам предоставит yup.

## Требуемый функционал

Реализации функционала формика, как хока, где инпут поле будет говорить что не так (подсвечиваться красным и выкидвать
ошибку).

Связанность annotation builder с yup, валидация для панели пропертей.

## Что требуется сделать

Определиться с механизмом взаимодействия. Отдельная вкладка, где вообще включается валиадцаия или к какждому полю своя
настройка. А может добавить поле для включения функционала валидации, после чего у полей появится соответствующее поле.

Еще есть вариант с компонентом, в который нужно класть валидируемые поля, но это такое себе.

## Предварительное решение

* Отдельная вкладка.
* Включаемая функциональность (на верхнем уровне по умолчанию включена и на уровне контрола по умолчанию выключена?).
  Нужна, чтобы не делать лишних оберток.
* К поддерживаемому инпуту будет поле из набора модификаторов (они настраиваемые?) из yup,
* Редактируемое поле сообщения об ошибке

## Порядок выполнения задачи

1. Разобраться с функциональность формика
2. Реализовать первые захардкоженные реализации
3. Создание секции
4. Тоггл включения
5. Враппер
6. Схемы (модификации)
7. Стили ошибок
