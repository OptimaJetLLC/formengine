# Drag and drop

Функциональность, являющаяся оберткой для компонентом, позволяющая менять расположение, размер и иные свойства
выделенного компонента.

Задействует библиотеку `react-dnd`

## Состав

### API

* `Editable` - враппер для компонентов. Предоставляет функционал, через который работает и взаимодействует Builder mode
  с компонентами.
* `AddedComponent` - Добавляемые компоненты. Инкапсулирует в себе переносимость (draggable) и отображение дефолтного
  внешнего вида компонента.

### Inners

* `Toolbar` - та плавующая плашка над выделенным компонентом, через который можно удалять компонент, клонировать.
* `DropZone` - те области, в которые кидают компоненты
* `useDnd` - основной хук данной фичи. Инкапсулирует drop, drag и drag&drop state.
* `useInnerDropZone` - Внутренние дропзоны, это дропзоны внутри компонентов, а не выше - ниже его. Например, в
  контейнерах. Отличительная особенность их, как правило они предоставляют биндинги.
* `useSelection` - функционал выбора компонента.
* `Resizers` - добавляет возможность влиять на размеер компонента, а также те плашки, с помощью которого это можно
  делать.

## Функциональность

* Менять расположение
* Менять размер компонента (влияние на стиль)
* Работа с контейнерами
  * Во премя drag подсвечивать места для вставки
  * Корректное взаимодействие с множественным местами вставок
