# FormEngine Next.js integration example

This code corresponds to Next.js [integration example](https://formengine.io/documentation/usage-with-nextjs).

## How to run

```shell
git clone git@github.com:OptimaJetLLC/formengine.git
cd formengine/examples/premium/with-nextjs/with-nextjs-v16
npm install
npm run dev
```
