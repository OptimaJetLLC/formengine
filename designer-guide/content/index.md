# Form Author Guide - Build forms without changing application code

Use this guide if you design forms in the visual editor and do not write application code. Start with an introduction to Designer, explore
the workspace on a real form, and then build your first form.

Developers who embed Designer in React should start with [Getting started](docs:formengine-designer/getting-started) and
[Installation](docs:formengine-designer/getting-started/installation) instead of this track.

## Summary

These pages are step-by-step docs, not a video course. They stay away from npm, React, and the API reference. Use screenshots and the
[live demo](https://demo.formengine.io/) to check your work as you go.
