# Form-wide errors and tooltips

Some display options apply to the **entire form**, not one field. You set them on the **Settings** tab under **Error settings** and
**Tooltip**.

## Error settings

<img src="/assets/guide/appearance/highlight-settings-error-block.png" alt="Error settings block with arrow pointing to the error type picker." />

1. Open **Settings** → **Error settings**.
2. Choose the error component and adjust the properties shown for it.
3. Turn on **Show** to display a sample error temporarily while you review those settings.

**Show** is a Designer preview aid. It is not saved as an "always show errors" setting for the live form.

Test in **Preview** with **Validate** after you change the type.

## Tooltip settings

<img src="/assets/guide/appearance/highlight-settings-tooltip.png" alt="Tooltip settings block with arrow pointing to the tooltip type picker." />

1. Open **Settings** → **Tooltip**.
2. Set the default tooltip style for components that support tooltips.
3. On individual fields, enable **Tooltip** on **Main** when you need extra help on one control.

Helper text on **Main** is usually better for always-visible hints. Tooltips show on hover or focus.

## Modal settings

<img src="/assets/guide/appearance/highlight-settings-modal.png" alt="Modal settings block with arrow pointing to the modal type picker." /> See [Modals for form authors](/behavior-and-validation/modals-for-form-authors).

## Summary

Use **Settings** for form-wide defaults for errors, tooltips, and modals. Field messages still come from **Rules** and **Main**.
