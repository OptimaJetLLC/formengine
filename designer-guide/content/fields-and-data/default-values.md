# Default values

**Default values** appear when the form first loads. Set them on **Main** for static defaults. Coordinate with developers for data from your systems.

## Set a static default

<img src="/assets/guide/workspace/main-tab-plain.png" alt="Main tab where default values are set." />

1. Select the field.
2. Open **Main**.
3. Enter **Default value** or **Value**.
4. **Preview** and confirm the field shows that text or selection.

## Runtime defaults

When values come from a user profile or API, developers pass initial data using the same field **Keys**. See [Prefill a form](/simple-data-driven-screens/prefill-a-form).

## Summary

Defaults live on **Main** for values configured in Designer. Match keys with developers for live prefill.
