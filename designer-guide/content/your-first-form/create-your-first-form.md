# Create your first form

You need an open form on the canvas before you add fields. You can create forms from the **Forms** tab or the main
menu.

:::tip Try it

<a href="#" onclick="openMinimalWindow('https://demo.formengine.io/?form=empty&view=mui'); return false;">Open starting form in demo</a> - opens the FormEngine demo in a popup window with the form this article starts from.

:::

## Before you begin

- Read [Use the left panel tabs](/meet-the-designer/use-the-left-panel-tabs).

## Open Designer

<img src="/assets/guide/workspace/builder-overview-plain.png" alt="Example form open on the Designer canvas." />

Open the Designer provided by your team, or use the demo link above. If a sample form is already open, continue to the next step to start
with an empty form.

## Add a new form from the menu

<img src="/assets/guide/manage-forms/highlight-header-menu-add-new-form.png" alt="Header menu open with Add a new form highlighted." />

1. Click the **menu** (hamburger) in the top-left.
2. Choose **Add a new form**.
3. Confirm the canvas clears or switches to a new empty screen.

## Use the Forms tab (when enabled)

<img src="/assets/guide/manage-forms/forms-tab-plain.png" alt="Forms tab for managing saved forms." />

1. Open the **Forms** tab on the left.
2. Click **Add** (or the equivalent control) to create a form.
3. Select a form name in the list to open it on the canvas.

:::info note

If **Forms** is missing, your environment may not include form storage. Use **Download** from the menu to save JSON locally, or ask your
administrator about storage.

:::

## Check the result

- An empty or newly named form on the canvas.
- `screen1` (or similar) as the root in the **Tree** tab.

## Summary

You need an active form on the canvas before adding components. Menu and **Forms** tab both create or open forms. Storage
features may vary by deployment.
