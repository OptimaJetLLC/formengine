# Валидация

Используется для полей формы - настраивается в секции с соответствующей вкладке, для пропертей - в аннотациях.

## Используемые библиотеки:

* [**yup**](https://www.npmjs.com/package/yup) - схем билдер, валидация значений, парсинг значений. (Простой, удобный,
  функциональный, можно задавать свои сообщения об ошибках)
