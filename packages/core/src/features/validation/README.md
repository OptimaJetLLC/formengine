# Валидация

Используется для полей формы - настраивается в секции с соответствующей вкладке, для пропертей - в аннотациях.

## Используемые библиотеки:

* [**Formik**](https://formik.org/) - обработка форм, api для работы с данными
* [**yup**](https://www.npmjs.com/package/yup) - схем билдер, валидация значений, парсинг значений. (Простой, удобный,
  функциональный, можно задавать свои сообщения об ошибках)

В дальнейшем, полагаю, следует заменить Formik на самописное решение
(референс [раз](https://github.com/gastonmorixe/formik-mobx/blob/master/src/index.tsx)
и [два](https://levelup.gitconnected.com/formik-with-react-hooks-and-mobx-1493b5fd607e). Аналог метода Field уже
постигла такая участь, потому что для работы с mobx оригинал не очень подходит
