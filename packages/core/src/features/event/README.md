# События, экшены

Используется для манипуляций событиями компонента, создания экшенов и прослушивания происходимых событий.

## Используемые библиотеки:

Никаких специфичных

## Функционал

* Редактирование / создание событий
* Добавление / редактирование экшенов, вызываемые в событии
* Подписка на события
* Типизрованное добавление новых экшенов

## API

* EventEditor - редактор функций (событий)
* useEvents - интегрирует события в компонент. Возвращает обработчики событий и карту экшенов этих событий.
* EventBus - класс, предоставляющий возможность слушать и реагировать на заданые события.
  Подписаться можно через свойство event у главного компонента формы.
