# Substitution

Используется для "биндингов" - аннотаций, которые заменяются на значения.

Сейчас подменяются только значения из пропсов компонентов. Позже могут использоваться для дат, генерации данных и прочее.

## Libraries

Используется библиотека [rc-marked-input](https://www.npmjs.com/package/rc-marked-input), которая позволяет легко объединять любые
компоненты с текстом с помощью аннотаций.

## API

* InputBindableText - инпут с кнопкой для добавления новых "биндингов"
* useSubstitution - подменяет значения {ключ компонента} на значение указанного компонента
* denoteBinds - превращает аннотированный текст в обычный
