# OptimaJet React Form Builder Print components library

This library is part of the [React Form Builder](https://formengine.io/) project.

This package contains print structure components: page breaks and print header/footer settings. To learn how to use the
package, see [Page break](https://formengine.io/documentation/components-library/structure-components/page-break/) and
[Print settings](https://formengine.io/documentation/components-library/structure-components/print-settings/), and the
[Form Author Guide](https://learn.formengine.io/preview-and-handoff/print-your-form/).
