# OptimaJet React Form Builder Sortable list component

This library is part of the [React Form Builder](https://formengine.io/) project.

The package contains `SortableList`, a Repeater that lets form users reorder rows by dragging. Add the component to your view next to
your UI kit. To learn how to use Repeater data and actions (`addRow`, `removeRow`), see the
[Repeater guide](https://www.formengine.io/documentation/using-repeater).
